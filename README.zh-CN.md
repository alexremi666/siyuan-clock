# 时钟（SiYuan Clock Plugin）

在思源笔记中以独立标签页显示时钟：

- 第一行：当前时间（如 `16:43:03`），大字号独占一行；
- 第二行：公历日期与星期（如 `2026年9月11日　星期五`），字号缩小、颜色变浅；
- 第三行：农历干支、生肖与日期（如 `丙午[马]年八月初一`），字号最小、颜色最浅；
- 全部颜色取自思源主题 CSS 变量，自动跟随明暗主题与自定义主题；
- 支持桌面端、桌面窗口、移动端与浏览器端。

## 使用方式

1. 在 集市 → 下载页（已下载）中启用「时钟」；
2. 点击顶栏的时钟图标，或在命令面板搜索「打开时钟」，即可打开时钟标签页；
3. 反复点击只会保留一个时钟标签页。

## 说明

- 农历换算内置 1900—2100 年数据，离线可用；
- 干支年以农历春节为界；
- 本项目由 AI 生成。
