# SiYuan Clock Plugin

A clock displayed in a custom SiYuan tab:

- Line 1: current time (e.g. `16:43:03`) in a very large font on its own line;
- Line 2: Gregorian date and weekday (e.g. `2026/9/11 Friday`) in a smaller, lighter font;
- Line 3: Chinese lunar date with stem-branch and zodiac (e.g. `丙午[马]年八月初一`) in the smallest, lightest font;
- All colors come from SiYuan theme CSS variables, so the plugin follows light/dark and custom themes automatically;
- Works on desktop, desktop-window, mobile and browser frontends.

## Usage

1. Enable "SiYuan Clock Plugin" in Bazaar → Downloaded;
2. Click the clock icon in the top bar, or run the "Open clock" command from the command palette;
3. Only one clock tab is kept no matter how many times you open it.

## Notes

- The lunar calendar lookup table covers 1900–2100 and works fully offline;
- The stem-branch year changes at the Chinese New Year;
- This project was generated with AI assistance.
